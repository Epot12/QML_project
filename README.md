# Hybrid Quantum Swin Transformers for Breast Cancer Screening

Project developed for the Quantum Machine Learning course of the MSc in Computer Engineering at the University of Florence.

## Overview
This project investigates hybrid quantum and classical versions of the Swin Transformer for breast cancer detection from ultrasound images. The models were trained using quantum simulators and then validated on real quantum hardware.

## Contents
- `QML_project.ipynb`: implementation, training and evaluation (GitHub may not render it; please download it)
- `Report_QML.pdf`: project report, describing the methodology and the results

## Tools
PyTorch, PennyLane
